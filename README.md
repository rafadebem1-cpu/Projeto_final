# Projeto_final
A partir do modelo treinado e serializado, construir, modularizar e documentar uma API  Web completa com FastAPI, implementando endpoints padronizados de monitoramento de saúde  (/health) e de inferência sob demanda (/predict ou /v1/predict), com esquemas de entrada e saída  validados via Pydantic e ciclo de vida otimizado.
